# 음성 대화 실기기 수동 검증

에뮬레이터는 마이크와 음성 인식 서비스가 불안정해서 실기기(한국어, Google 음성 인식 설치)에서 한다.
준비: `local.properties`에 `GEMINI_API_KEY`를 넣고 빌드한 debug APK, 약 "생리통약"을 하나 등록.

## 1. 마이크 권한
- [ ] 첫 실행에서 마이크 버튼 → 권한 대화상자 → **허용** → 바로 "듣고 있어요…"
- [ ] 권한 초기화 후 마이크 버튼 → **거부** → "마이크 권한이 필요해요. 설정에서 허용해 주세요", 듣기 시작하지 않음
- [ ] 거부 후 설정에서 허용하고 시트를 다시 열면 정상 동작
- [ ] 이미 허용된 상태에서는 대화상자 없이 바로 듣기

## 2. 음성 인식 실패
- [ ] 아무 말도 안 하면 12초 안에 "못 들었어요. 마이크를 눌러 다시 말해 주세요"
- [ ] 안 들리는 웅얼거림 → 같은 안내, 마이크 버튼으로 다시 시도 가능
- [ ] 음성 인식 서비스가 없는 기기/설정이면 "이 기기에서 음성 인식을 쓸 수 없어요"
- [ ] 소음이 큰 곳에서 인식기가 끝나지 않아도 12초 뒤 멈춤

## 3. LLM 실패 / 오프라인
- [ ] 비행기 모드에서 "생리통약 먹었어" → "잘 못 알아들었어요. 다시 말씀해 주세요", 이어서 듣기
- [ ] `GEMINI_API_KEY` 없이 빌드한 APK → 모든 말에 같은 안내
- [ ] 잘못된 키 → 같은 안내, logcat `GeminiVoiceIntent`에 실패 로그
- [ ] 10초 안에 응답이 없으면 실패로 처리하고 앱이 멈추지 않음
- [ ] 네트워크 복구 후 같은 말이 정상 처리

## 4. TTS 응답
- [ ] 응답이 한국어로 소리 나고, 같은 문구가 화면에 보임
- [ ] 응답 중 시트를 닫으면 소리가 바로 멈춤
- [ ] 한국어 TTS 음성을 지우거나 끈 기기: 소리 없이 화면 문구만 나오고 대화는 이어짐
- [ ] 약 이름이 영문으로 끝나는 경우("비타민D") 문구가 어색하지 않음

## 5. 입구 3종 (모두 앱을 열면서 바로 듣기)
- [ ] 목록 상단 마이크 버튼 → 시트가 열리고 듣기 시작
- [ ] 앱 아이콘 길게 누르기 → "음성으로 말하기" → 시트와 듣기 (앱이 꺼진 상태, 켜진 상태 둘 다)
- [ ] 딥링크: `adb shell am start -a android.intent.action.VIEW -d pillreminder://voice`
- [ ] extra: `adb shell am start -n com.mg.pillreminder/.MainActivity --ez com.mg.pillreminder.extra.START_VOICE true`
- [ ] 화면 회전 후 시트가 다시 자동으로 열리지 않음
- [ ] 이미 열린 앱에서 입구를 다시 쓰면 시트가 다시 열림
- [ ] (미정) 빅스비 빠른 명령어 "앱 열기"로 PillReminder 지정 → 앱이 열리는지, 바로 듣기까지 되는지 / 잠금 화면에서도 되는지

## 6. 대화 흐름
- [ ] "생리통약 먹었어" → "복약 기록을 체크했어요. 다음에 언제 알려드릴까요?" → 계속 듣기
- [ ] 이어서 "4시간 뒤에" → "4시간 뒤 … 에 알려드릴게요." → 목록 "다음 알림"과 실제 알림 확인
- [ ] "생리통약 언제 먹었지?" → "오늘 HH:mm에 드셨어요. … 지났어요."
- [ ] 기록 없는 약 조회 → "…, 아직 복용 기록이 없어요."
- [ ] 등록 안 된 약("타이레놀 먹었어") → "등록되지 않은 약이에요. 새로 등록할까요?" → "응" → 이름이 채워진 등록 시트 / "아니" → "알겠어요."
- [ ] 약 이름 없이 "4시간 뒤에"를 처음 말하면 "어떤 약인지 같이 말씀해 주세요."
- [ ] 시트를 닫았다 다시 열면 직전 약을 기억하지 않음
- [ ] 마이크 버튼을 눌러 다시 말해도 같은 대화 안에서는 직전 약을 기억

## 7. "먹었어" 기록 후 후속 질문
- [ ] 알림의 "먹었어" 버튼으로 기록한 뒤 음성으로 "생리통약 언제 먹었지?" → 방금 전 기록으로 답함
- [ ] 음성으로 기록한 뒤 약 목록의 "마지막 복용"이 갱신됨
- [ ] 같은 약을 간격 일정하게 4번 기록(시각은 DB나 시스템 시계로 조정) 후 "먹었어" → "최근 N시간마다 드셨네요. N시간마다 알려드릴까요?"
  - [ ] "응" → "N시간마다 알려드릴게요. 첫 알림은 …" → 목록에 주기 알림
  - [ ] "아니" → "이 약은 다시 제안하지 않을게요." → 이후 기록해도 제안 없음, 목록 배너도 사라짐
- [ ] 제안 질문에 엉뚱한 말을 하면 질문을 버리고 새 말로 처리
